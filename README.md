# Geo Gold Realty editable site

The website is a plain static site. Edit the copy, links, and structure in `dist/index.html`; adjust colors, spacing, and image URLs in `dist/styles.css`; and edit small interactive behavior in `dist/app.js`.

The form buttons open a pre-addressed email to `hello@geogoldrealty.com`. Replace that behavior with a lead-management service before relying on the forms for production leads.

The header is intentionally black with white navigation text, per the requested design update.
